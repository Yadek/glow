Windows не умеет управлять яркостью внешнего монитора. Ползунок в параметрах системы двигает только встроенную матрицу ноутбука, а всё, что подключено по HDMI или DisplayPort, приходится настраивать физическими кнопками на корпусе.

Glow добавляет в системный трей ползунок, который меняет яркость **в самом мониторе** — по протоколу DDC/CI, который монитор и так понимает, а не затемняет картинку тёмным слоем поверх. Каждый подключённый экран получает свой ползунок, плюс отдельный ночной режим для тёплых цветов вечером.

Программа — один автономный `.exe`, в простое почти не тратит процессор, бесплатная и с открытым исходным кодом. Если вы искали замену **ClickMonitorDDC**, которую не обновляли уже несколько лет, или альтернативу **Twinkle Tray** и **Monitorian** — Glow делает ровно эту работу.

## Установка

1. Скачайте **`Glow-Setup-x.y.z.exe`** из [последнего релиза](https://github.com/Yadek/glow/releases/latest).
2. Запустите и отметьте **Запускать Glow автоматически при старте Windows**.
3. Glow появится в трее. Готово.

Не хотите ничего устанавливать? Возьмите **`Glow-x.y.z-portable.exe`** из того же релиза и запускайте напрямую — он полностью автономный и ничего после себя не оставляет.

**Что нужно:** Windows 10 или 11 (64-бит) и монитор с поддержкой DDC/CI — у большинства внешних настольных мониторов она есть. Если ползунок яркости не появился, смотрите [Не работает?](#не-работает).

## Как пользоваться

Кликните по иконке **Glow** в системном трее (рядом с иконкой звука) → появится окно с карточкой **Все мониторы**, которая управляет сразу всеми экранами. Нажмите **Каждый монитор отдельно** — раскроется по карточке на монитор, повторное нажатие свернёт обратно; окно запоминает, как вы его оставили.

В каждой карточке есть **строка с солнцем** (аппаратная яркость по DDC/CI) и **строка с луной** (ночной режим). Общие ползунки держат то значение, которое *вы* им задали: настройка отдельного экрана их не сдвигает, поэтому общий ползунок остаётся тем, что вы выставляете, а не бегущим средним. Его переключатель показывает *Разное*, когда состояние экранов не совпадает.

Правый клик по иконке — **Ночной режим на всех мониторах**, **Запуск при старте Windows** и **Выход**. Клик средней кнопкой переключает ночной режим везде, не открывая окно.

## Возможности

- **Настоящая аппаратная яркость** — управляет внешними мониторами по **DDC/CI** (`Dxva2.dll`), а не программным затемнением. Меняется подсветка самого монитора, поэтому вы получаете и экономию энергии, и комфорт для глаз, а не притушенную картинку.
- **Мультимониторность** — сам находит все подключённые экраны и показывает отдельный ползунок для каждого, подписанный реальной моделью (читается из EDID).
- **Ночной режим на каждый монитор** — своя теплота для каждого экрана **или** сразу для всех из карточки *Все мониторы*. Работает даже на экранах без DDC/CI, потому что идёт через гамма-рампы, а не через цветовые настройки самого монитора.
- **Настройки не теряются** — ночной режим сохраняется по EDID-идентификатору экрана, поэтому переживает перезагрузку и «переезжает» вместе с монитором на другой порт. Автоматически применяется заново после сна, смены разрешения или разблокировки — там, где Windows молча сбрасывает гамму.
- **Почти нулевой расход ресурсов** — никаких фоновых таймеров и опроса; программа спит в цикле сообщений и просыпается только по клику. CPU в простое ≈ 0%.
- **Один автономный `.exe`** — без установки среды .NET.
- **Авто-локализация** — язык интерфейса следует за языком Windows (English / Русский), фоллбек на английский.
- **Под тему системы** — следует за светлой/тёмной темой Windows и акцентным цветом, со скруглёнными углами Windows 11.
- **Тихая автозагрузка** — по желанию запуск вместе с Windows через `HKCU\…\Run`.
- **Автообновление** — проверяет GitHub Releases и обновляется с вашего подтверждения. Беты не предлагает.
- **Чистое удаление** — убирает приложение, ключ автозагрузки и все настройки; следов не остаётся.

## Не работает?

**У монитора нет ползунка яркости, только ночной режим.**
Этот экран не отдаёт DDC/CI. Две частые причины: это встроенная матрица ноутбука — большинство из них действительно не поддерживают протокол — либо DDC/CI выключен в собственном меню монитора, где он обычно спрятан в разделе *Settings*, *Others* или *OSD*. Включите его там и перезапустите Glow. Экраны без DDC/CI всё равно получают карточку, но только с ночным режимом.

**Ночной режим сам выключается или конфликтует с Windows.**
Ночной режим управляет гаммой экрана — той же ручкой, которой пользуется системная функция *Ночной свет*: побеждает тот, кто записал последним. Если пользуетесь режимом Glow, выключите системный в *Параметры → Система → Дисплей*.

**Ночной режим ничего не делает на одном из экранов.**
Скорее всего, этот экран работает в режиме HDR, который гамма-рампы игнорирует полностью. Отключите HDR для этого дисплея, если хотите пользоваться на нём ночным режимом.

**Яркость сбрасывается после сна или смены разрешения.**
Так быть не должно — Glow применяет настройки заново после сна, разблокировки и изменения конфигурации экранов. Если на вашем железе это всё-таки происходит, [заведите issue](https://github.com/Yadek/glow/issues/new) и укажите модель монитора.

Что-то ещё или ведёт себя странно? [Заведите issue](https://github.com/Yadek/glow/issues/new) — вопросы приветствуются не меньше, чем сообщения об ошибках.

## Бета-сборки

Версии с суффиксом `-beta` публикуются как **предрелизы** GitHub, и качать их нужно прямо со [страницы релизов](https://github.com/Yadek/glow/releases) — ссылка «последний релиз» выше всегда ведёт на свежую стабильную сборку.

Бета-сборки **никогда не проверяют обновления сами**, чтобы не отвлекать во время тестирования; пункт **Проверить обновления** в меню трея по-прежнему работает по запросу. Стабильным установкам бета тоже не предлагается: проверка смотрит только на последний *стабильный* релиз.
