# Glow 1.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for inline execution, or superpowers:subagent-driven-development only if the user selects delegation. Steps use checkbox syntax for tracking.

**Goal:** Выпустить проверяемое обновление Glow 1.3.0 со стеклянным интерфейсом, превью обоев каждого монитора и автоматически сохраняемой статистикой GitHub.

**Architecture:** Сохраняются WinForms, DisplayManager, DDC/CI и NightMode. Сервис обоев получает неизменяемый снимок идентификаторов дисплеев и возвращает ограниченные по размеру изображения; UI владеет показанными изображениями и отбрасывает устаревшие результаты. Независимый сборщик GitHub хранит JSON и SVG в ветке stats.

**Tech Stack:** C# / .NET 8 / WinForms / Win32 COM и DWM; Python standard library для статистики; GitHub Actions. Продукт не получает сторонних зависимостей.

**Spec:** ../specs/2026-10-16-glow-1.3-design.md, согласован 16 октября 2026.

## Global Constraints

- Целевая версия по указанию пользователя — 1.3.0.
- Сохранить аппаратную яркость DDC/CI, индивидуальный ночной режим, общий регулятор, RU/EN, поведение после сна и горячего подключения.
- README.md и README.ru.md должны обновляться синхронно.
- Не добавлять AI-подписей и Co-authored-by; реальную историю авторов не менять.
- Не добавлять постоянный опрос и запись миниатюр на диск при скрытом popup.
- Живой захват не входит в гарантии 1.3.0.
- Коммит и push — только после подтверждения прав GitHub и проверок.
- Пароли и токены не запрашивать в переписке, секреты настраивать через интерфейс GitHub.

## Review Focus

- Переставленные, зеркальные или повторяющиеся мониторы: неоднозначное соответствие не должно давать карточке чужие обои; Task 1 проверяет дубликаты идентификаторов и геометрии.
- Быстрое закрытие/открытие popup во время загрузки: старый результат не меняет новые карточки и освобождает изображение; Task 3 проверяет поколение запроса и отмену.
- Изменение прозрачности Windows и высокая контрастность при работающем приложении: следующее открытие получает читаемый fallback; Task 4 проверяет матрицу условий.
- Частично обновившийся traffic за текущий UTC-день: повторный запуск заменяет дневное значение, не удваивает его; Task 5 проверяет overlap и null.
- Повреждение сохранённой истории либо отказ сети: Action завершается ошибкой без записи пустой истории; Task 5 проверяет оба сценария.

## Разделение работ и файлов

Три части имеют отдельные циклы проверки: A — обои (Tasks 1–3), B — интерфейс (Task 4), C — статистика (Tasks 5–6). A и C могут быть приняты независимо; B использует интерфейс A. Итоговая проверка — Task 7. Это один согласованный выпуск с отдельными проверяемыми изменениями, а не миграция архитектуры.

Новые файлы:

- `src/Glow/Wallpapers/WallpaperModels.cs`: снимки дисплеев, источники превью и владение результатом.
- `src/Glow/Wallpapers/DesktopWallpaperProvider.cs`: COM IDesktopWallpaper, сопоставление и параметры размещения.
- `src/Glow/Native/DesktopWallpaperInterop.cs`: точный ABI COM, GUID, enum и RECT.
- `src/Glow/Wallpapers/WallpaperEngineProvider.cs`: обнаружение работающей программы, ограниченная команда и проверка соответствия.
- `src/Glow/Wallpapers/WallpaperPreviewService.cs`: fallback, декодирование, уменьшение, отмена и ограниченный кэш.
- `src/Glow/UI/MonitorPreview.cs`: миниатюра с закруглением и корректным освобождением изображения.
- `src/Glow/UI/WindowBackdrop.cs`: выбор и применение системного эффекта, непрозрачный fallback.
- `src/Glow/UI/PopupSettingsMenu.cs`: настройки из шапки, события для TrayContext.
- `tests/Glow.Tests/Glow.Tests.csproj`, `Program.cs`, `WallpaperTests.cs`, `PreviewLifetimeTests.cs`, `BackdropTests.cs`, `SliderTests.cs`: простой исполняемый тестовый проект с BCL-assertions и ненулевым exit code при ошибке, без NuGet-пакетов тестового фреймворка.
- `src/Glow/Properties/AssemblyInfo.cs`: InternalsVisibleTo только для Glow.Tests.
- `tools/github_stats.py`, `tools/test_github_stats.py`: сбор, слияние, SVG и offline-тесты.
- `.github/workflows/stats.yml`: расписание и запись ветки stats.

Изменяемые файлы: DisplayCatalog.cs (идентификатор интерфейса и геометрия в DisplayInfo), BrightnessPopup.cs (превью и шапка), BrightnessSlider.cs (отрисовка и клавиатура), RoundedPanel.cs и Theme.cs (поверхности), TrayContext.cs и AppSettings.cs (общие настройки), Strings.cs (RU/EN), Glow.csproj (версия), Glow.sln (тестовый проект), build.yml (проверки и исключение stats), оба README и CONTRIBUTING.md.

## Task 1: Windows-обои с проверенным сопоставлением мониторов

**Interfaces:**

- `DisplayInfo` получает `string? InterfacePath` и `Rectangle Bounds`; текущие Key/Name/DeviceName/HMonitor сохраняются.
- `WallpaperDisplay(string Key, string? InterfacePath, Rectangle Bounds)` — снимок, без аппаратных handles.
- `WallpaperCandidate(string Path, WallpaperSource Source, Rectangle? CropBounds)`; `WallpaperSource` = Windows, WallpaperEngine.
- `DesktopWallpaperProvider.GetCandidate(WallpaperDisplay display)` возвращает `WallpaperCandidate?` на STA-потоке; отсутствие обоев возвращает null.
- `MatchMonitor(WallpaperDisplay display, IReadOnlyList<WallpaperDisplay> candidates)` возвращает единственное соответствие либо null. Эти модели и helper internal, доступны тестовой сборке.
